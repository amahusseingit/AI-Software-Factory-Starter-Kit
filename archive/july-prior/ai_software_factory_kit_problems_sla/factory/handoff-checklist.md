# Handoff Checklist
# Problems SLA Dashboard

## Product Owner Handoff Checklist

- [ ] SRS read.
- [ ] Shared log read.
- [ ] Epics created.
- [ ] Stories created.
- [ ] Acceptance criteria written in Given/When/Then.
- [ ] Data-quality rules included.
- [ ] Scope validation included.
- [ ] Reconciliation requirements included.
- [ ] Test expectations included.
- [ ] Shared log updated.
- [ ] Architect handoff notes written.

---

## Architect Handoff Checklist

- [ ] PO stories read.
- [ ] Shared log read.
- [ ] Existing repository architecture inspected.
- [ ] Backend components identified.
- [ ] Frontend components identified.
- [ ] Data model designed.
- [ ] API contracts designed.
- [ ] Calculation algorithm defined.
- [ ] Migration approach defined.
- [ ] Authorization model defined.
- [ ] Testing impact documented.
- [ ] Shared log updated.
- [ ] Developer handoff notes written.

---

## Developer Handoff Checklist

- [ ] SRS read.
- [ ] PO stories read.
- [ ] Architect output read.
- [ ] Shared log read.
- [ ] Implementation plan approved.
- [ ] Code implemented.
- [ ] Tests added/updated.
- [ ] Build commands executed where possible.
- [ ] Test commands executed where possible.
- [ ] Changed files listed.
- [ ] Deviations documented.
- [ ] Shared log updated.
- [ ] QA handoff notes written.

---

## QA / Static Analysis Handoff Checklist

- [ ] SRS read.
- [ ] PO stories read.
- [ ] Architect output read.
- [ ] Developer log read.
- [ ] Shared log read.
- [ ] QA plan approved.
- [ ] Code review performed.
- [ ] Static analysis performed.
- [ ] Unit tests executed.
- [ ] Integration/API tests executed where applicable.
- [ ] Frontend tests executed where applicable.
- [ ] Acceptance criteria validated.
- [ ] Defects documented.
- [ ] Release recommendation written.
- [ ] Shared log updated.
