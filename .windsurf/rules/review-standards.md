# Review Standards

Every review must check:
- spec alignment
- architecture compliance
- security and correctness
- maintainability
- future compatibility of the current slice

Every review must return:
- issues by severity
- top 3 risks
- exact recommendations
- final recommendation:
  - PASS or BLOCKED under governance/protocol.md
