# Handoff contract compatibility pointer

Use the maintained [role execution handoff](role-handoff-template.md).
It includes authorization sources, revisions, scope, raw command evidence,
criterion mapping, independent actors, findings and an explicit stop point.

The [canonical protocol](../governance/protocol.md) and
[security policy](../governance/security-policy.md) control.
A handoff proposes the next role; it never approves that role or closes a task.
