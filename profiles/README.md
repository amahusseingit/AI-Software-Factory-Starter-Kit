# Explicitly selected profiles

Profiles describe optional adaptations. They are not default requirements and do not authorize execution. [Canonical protocol](../governance/protocol.md) and [security policy](../governance/security-policy.md) always apply.

- [Optional .NET / SQL Server / Angular / Flutter](dotnet-sqlserver-angular-flutter.md): repository-specific stack mapping and validation considerations, only when explicitly selected.
- [Problems SLA historical example](problems-sla-example.md): non-authoritative preservation of detailed historical business/scenario content. The supplied updated kit's SRS is a placeholder; obtain the current authoritative SRS before any domain use.

Record profile selection, applicable components, source/spec revisions, exclusions and approval in the task's planning/requirements records. Selection is not approval of every role plan, command, migration or release action. A domain example cannot become authoritative merely by being copied into a project.
