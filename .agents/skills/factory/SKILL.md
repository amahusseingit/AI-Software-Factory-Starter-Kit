# Factory entry point

Locate the repository root containing AGENTS.md (three parent directories above
this skill folder). Read AGENTS.md, ORCHESTRATOR.md and
skills/codex-factory-adapter/SKILL.md there, followed by the canonical protocol,
security policy and selected role playbook required by that adapter.

Use existing specialist skills under skills/ after routing. Present the current
role's plan and approval boundary. Do not infer approval, independent QA or
closure from a prompt, example, validation result or role label.
