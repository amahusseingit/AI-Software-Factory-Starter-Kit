# Signoff record template
TEMPLATE ONLY, NOT EVIDENCE. Append real records only from verified external user approvals.

Required: unique entry/task/run IDs; actor; accountable human; original approval message/source ID; action; role; scope_hash; plan_hash; candidate_revision; UTC issued/expiry; conditions; decision PASS/BLOCKED; evidence links/hashes; previous-entry hash. See [protocol.md](protocol.md). Never prefill PASS, names or approvals. Preserve superseded records and explicitly invalidate affected approvals when revisions change.
