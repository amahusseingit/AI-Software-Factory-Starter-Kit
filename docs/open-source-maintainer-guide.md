# Open Source Maintainer Guide

## Keep the kit generic
Do not merge business-domain-specific requirements into the core repository.

## Prefer reusable patterns
When possible, add generic skills, templates, references, or packs.

## Keep docs current
When adding capabilities, update:
- `README.md`
- `CHANGELOG.md`
- relevant docs index pages
