# Lifecycle

## DEFINE
Goal: establish scope, workflows, roles, rules, validations, integrations, and constraints.

Entry commands: `START-PROJECT` and `SPEC`.

## PLAN
Goal: convert scope into verifiable vertical slices.

## BUILD
Goal: implement behavior, not shells.

## VERIFY
Goal: validate correctness through tests and evidence.

Execution command: `commands/TEST.md`.

## REVIEW
Goal: block incomplete, unsafe, or low-quality delivery.

## SHIP
Goal: make release practical and supportable.

## CLOSE
Goal: reconcile current independent evidence and record closure only after
explicit user action `close`, following governance/protocol.md. Closure grants
no merge, deployment or successor-role execution permission.
