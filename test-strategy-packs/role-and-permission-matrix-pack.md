# Role and Permission Matrix Test Strategy Pack

Use when multiple roles, ownership rules, or data isolation rules are in scope.

## Focus
- role-based visibility
- allowed vs forbidden actions
- ownership checks
- session and token boundary behavior

## Minimum expectations
- backend authorization tests
- UI visibility tests for critical roles
- negative tests for unauthorized actions
- data isolation tests
