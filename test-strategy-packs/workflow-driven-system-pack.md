# Workflow-Driven System Test Strategy Pack

Use when the system is dominated by step-based flows, approvals, orchestrations, or journey completion.

## Focus
- happy path workflow completion
- alternate paths
- blocked transitions
- rollback or reversal behavior
- audit trail and status progression

## Minimum expectations
- workflow integration tests
- status transition tests
- UI step validation tests
- failure-path and retry tests where applicable
